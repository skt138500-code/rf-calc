CNN 영어 스크립트 가져오는 법
  1. 유튜브에서 CNN 10을 찾아 영상을 엽니다. 10분짜리 뉴스라 속도와 단어가 연습용으로 알맞아요.
  2. 설명의 더보기 → 스크립트 표시에서 텍스트를 복사합니다. 폰 앱에서 복사가 안 되면 PC 브라우저에서 하세요. CNN 기사 본문도 돼요.
  3. 위 칸에 붙여넣고 해석 만들기. 0:03 같은 시간 표시는 자동으로 지워요.
  4. 영상으로 볼 때 한글 자막: 자막(CC) → 설정 → 자막 → 자동 번역 → 한국어 (PC 유튜브).

API 키 받는 법
  1. platform.claude.com에 로그인합니다. Pro 요금제와는 별도로, 여기서 쓴 만큼 결제해요.
  2. 결제(Billing)에서 크레딧을 조금 충전합니다. 5달러면 한참 써요.
  3. API Keys → Create Key로 키를 만들고 복사해서 위 칸에 붙여넣으세요.
  4. 사용 한도(Limits)를 낮게 걸어 두면 혹시 키가 새도 안심이에요.
