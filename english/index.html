API 키 받는 법
  1. platform.claude.com에 로그인합니다. Pro 요금제와는 별도로, 여기서 쓴 만큼 결제해요.
  2. 결제(Billing)에서 크레딧을 조금 충전합니다. 5달러면 한참 써요.
  3. API Keys → Create Key로 키를 만들고 복사해서 위 칸에 붙여넣으세요.
  4. 사용 한도(Limits)를 낮게 걸어 두면 혹시 키가 새도 안심이에요.
platform.claude.com 열기

키 없이도 돼요. 해석·질문 버튼을 누르면 Claude 앱의 트레이너가 열려서 Pro 요금제로 쓰고, 결과는 '홈 앱으로 보내기'로 가져오면 됩니다.

자막 자동 받기

영상을 열면 앱이 유튜브 영어 자막(시간 포함)을 바로 받아와요. Supadata 무료 키를 한 번만 넣으면 돼요. 월 100개 영상까지 무료, 카드 등록 없음.

  1. 아래 가입 페이지 열기 → 구글 계정 등으로 가입
  2. 대시보드에 보이는 API Key를 복사
  3. 돌아와서 아래 칸에 붙여넣고 저장
가입 페이지 열기

한 번 받은 자막은 폰에 저장돼서 다시 열 때는 쓰지 않아요. 키는 이 폰에만 있고 백업 코드에도 안 들어가요.

직접 붙여넣기
  1. 자막 사이트 열기를 누르면 이 영상 링크가 복사돼요. 사이트 입력칸에 붙여넣고 Get Transcript.
  2. Include timestamps(시간 표시)를 켜고 Copy.
  3. 돌아와서 아래 붙여넣기 → 자막 만들기. 시간 표시가 있으면 영상과 문장이 정확히 맞춰져요.

아리랑 뉴스처럼 방송사 홈페이지에 원고가 있으면 그 글을 넣어도 돼요. 시간 표시가 없는 글은 위치를 어림해서 맞추고, 자막 맞추기로 고칠 수 있어요. 스크립트 없이도 영상의 영어 자막(CC)은 볼 수 있어요.
