    열쇠(토큰) 만들기

    1. 아래 버튼으로 GitHub 열기. 오른쪽 위 계정이 skt138500-code인지 확인
    2. Repository access에서 Only select repositories → rf-calc 고르기
    3. 아래 Permissions에서 Contents와 Actions가 Read and write인지 확인 (미리 골라뒀어요)
    4. 맨 아래 초록색 Generate token → 한 번 더 확인 → 나온 열쇠 복사
    5. 이 앱으로 돌아와 아래에 붙여넣고 연결하기
    GitHub에서 열쇠 만들기

    열쇠는 이 폰에만 저장되고, rf-calc 저장소 내용만 바꿀 수 있어요. 폰을 잃어버리면 GitHub → Settings → Developer settings → Personal access tokens에서 이 열쇠를 지우면 돼요.
