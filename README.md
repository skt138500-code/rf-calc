# RF 공학계산기

광고 없는 오프라인 공학계산기. 휴대폰에서 아래 주소를 열고 홈 화면에 추가하면 인터넷 없이 앱처럼 쓸 수 있습니다.

https://skt138500-code.github.io/rf-calc/

- 계산: 삼각·역삼각, ln/log, 지수, 루트, 팩토리얼, EE, Ans, DEG/RAD, NORM/SCI/ENG(SI 접두어)
- RF: dBm⇄W, 주파수→파장, 스킨 깊이, VSWR⇄반사손실⇄|Γ|, 순방향/반사 전력, dB⇄비율
- 전원: SSPA RF 출력·DC 효율 → DC 전류, 분전반 전류, 차단기, 케이블 굵기(IEC 60364-5-52 참고), 접지선, 발열량

## 내 주식
관심종목 현재가·등락률, 보유 손익(금액/퍼센트, 국내·미국 나눠 보기), 기간별 차트, 원화 환산, 배당(종목별·월별 예상), 섹터 비중. 앱에서 바로 종목 추가·삭제(GitHub 연결 시). https://skt138500-code.github.io/rf-calc/stocks/

## 차량관리
차 여러 대의 다음 정비(엔진오일·타이어·배터리·정기검사 등), 정비 이력, 연도별·항목별 비용. 주행거리는 마지막 기록 이후 평소 달린 거리로 추정합니다. 기록은 폰에만 저장되고 백업 코드로 옮길 수 있습니다. https://skt138500-code.github.io/rf-calc/car/

## 영어 입 트레이너
학회 발표·질의응답 표현을 듣고 따라 말하기(마이크로 채점), 유튜브 뉴스 영상(아리랑·CNN·BBC 등)을 보면서 아래 영어 스크립트·해석이 재생 위치를 따라가게 듣기, 국제 뉴스 기사나 발표 대본을 문장별 해석과 함께 듣기, 예상 질문에 답하고 코칭 받기. 매일 10분 할 일과 연속 학습 기록. AI는 API 키를 넣으면 앱 안에서, 없으면 Claude 앱으로 넘겨서 씁니다. https://skt138500-code.github.io/rf-calc/english/
